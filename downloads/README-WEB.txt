INSTALACJA — WEB
1. Rozpakuj ZIP. Uruchom: python3 -m http.server 8765
2. Otwórz http://127.0.0.1:8765/dloop.html
Albo użyj wersji na żywo (PWA: w Chrome „Zainstaluj aplikację”).

INSTALACJA — ANDROID
Pobierz D7-DJ-Studio.apk (1.3.0). Kopia 1.2.0 zostaje jako D7-DJ-Studio-v1.2.0.apk.
Zezwól na źródła nieznane, zainstaluj. Pakiet com.danieldydo.d7djstudio, podpis debug (nie Sklep Play).

INSTALACJA — WINDOWS
Złóż part1+part2 (Polacz-i-uruchom.bat), rozpakuj, uruchom D7-DJ-Studio.exe
(online → wersja na żywo; offline → wbudowana kopia 1.3.0). Windows może pokazać SmartScreen.

INSTALACJA — CHROME (nowe rozszerzenie „D7 DJ Studio”)
1. Rozpakuj d7-dj-studio-extension.zip
2. chrome://extensions → Tryb dewelopera → Załaduj rozpakowane
Stare rozszerzenie Super DJ Loops zostawiamy osobno, bez zmian.
