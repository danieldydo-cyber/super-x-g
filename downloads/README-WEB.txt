NOWOŚĆ — Boty / Auto · Versus
W D7 DJ Studio: grupa Boty / Auto z Grok DJ, Super Sound DJ i Versus
(tury co 16 taktów, różne style, tablica wyników, energia tłumu, awatary, zwycięzca).
Dostępne w wersji na żywo, PWA, Web ZIP i nowym rozszerzeniu Chrome.
APK Android 1.2.0 na razie bez Versus (ta sama linia produktu).

INSTALACJA — WEB
1. Rozpakuj ZIP. Uruchom: python3 -m http.server 8765
2. Otwórz http://127.0.0.1:8765/dloop.html
Albo użyj wersji na żywo (PWA: w Chrome „Zainstaluj aplikację”).

INSTALACJA — ANDROID
Pobierz D7-DJ-Studio.apk, zezwól na źródła nieznane, zainstaluj.
Pakiet com.danieldydo.d7djstudio, podpis debug (nie Sklep Play).

INSTALACJA — WINDOWS
Rozpakuj D7-DJ-Studio-win32-x64.zip i uruchom D7-DJ-Studio.exe
(online → wersja na żywo; offline → wbudowana kopia). Windows może pokazać SmartScreen.

INSTALACJA — CHROME (nowe rozszerzenie „D7 DJ Studio”)
1. Rozpakuj d7-dj-studio-extension.zip
2. chrome://extensions → Tryb dewelopera → Załaduj rozpakowane
Stare rozszerzenie Super DJ Loops zostawiamy osobno, bez zmian.

W paczce: dloop, PWA, 162 pętle. Bez teledysków Maria 19.
Wsparcie: tylko BLIK 730 377 357. Jedno okno · ✕ · ⛶ · Esc.
